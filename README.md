
# Python Calculator

A simple calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division

## Technologies Used
- Python 3

## Installation

Clone the repository:

```bash
git clone https://github.com/username/python-calculator.git
```

Navigate to the project folder:

```bash
cd python-calculator
```

## Usage

Run the program:

```bash
python calculator.py
```
